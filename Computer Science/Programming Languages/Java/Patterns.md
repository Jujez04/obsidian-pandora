There are some classes that are commonly used when programmers faces problems. These classes can be collected in a way that they forms a *pattern*. Patterns are incredibile instruments for designing solution structures. 

They can be classified as:

# Creational Patterns
[[Factory pattern]]  --> only for classes 
The others are bounded for objects:
[[Abstract Factory pattern]] 
[[Prototype pattern]]
[[Singleton pattern]]
[[Builder pattern]]
# Behavioural Patterns
[[Adapter pattern]] --> both for classes and objects
Exclusively for objects:
[[Proxy pattern]]
[[Facade pattern]]
[[Composite pattern]]
[[Bridge pattern]]
[[Decorator pattern]]
