# Key Features
- General-purpose programming language
- Combines low-level hardware access with high-level programming features
- Simple and efficient by compiling the program directly into machine code
- Portability: that means any platforms or operating system can compile C code
- Low level access through the use of pointers and manipulation of hardware registers
- Modularity achieved by code organization with the division of headers (.h) and source code (.c)

# History
- Developed in the early 1970s by Dennis Ritchie at Bell Labs.
- C stem from the BCPL language, developed by Martin Richards and evolved into the language B, that was written by Ken Thompson.
- In 1983, the American National Standards Institute (ANSI) established a committee to provide a modern, comprehensive definition of C, declaring the **ANSI C** lately in 1988. This standard is based on the reference manual.
- The first important feature is a new syntax for declaring and defining functions. 
- The second significant contribution is the new definition of the standard library.
- From that point there had been developing several versions of C:
	- C89
	- C99
	- C11
	- C18
	- ...
